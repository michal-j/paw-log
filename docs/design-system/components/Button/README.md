Two buttons: primary for the one action a screen is about (+ Add, Save), ghost for everything else (Jump to date, Filters, language).

Primary: `mint-top` to `mint` gradient, `on-mint` label, `shadow-primary`, no border. Ghost: white to `surface-tint` gradient, 1px `line-strong` border, `shadow-button`. Both are 34px high, `radius-md`, `button` text style. One primary per screen. Hover on ghost darkens the border to #b4c0ba; pressed state drops opacity to 0.55 to 0.78. Focus is a 2px `mint-deep` outline, 2px offset. Extend the hit area to 44px with an invisible `::after`. The consumer provides the label and handler.
