The chip that marks a health event on a day. Kinds: vet visit (cyan, heart-line glyph, count where it stands for several), symptoms (orange "!" and count), note (white outlined page, once a day, no count), photo (camera), Frontline ("F"), deworming ("D"), and the neutral "+N" chip for the badges a busy Timeline row has no room for (JCB-26, JCB-69; `fitBadges`).

Each kind except "+N" has four tokens: `badge-<kind>-top`, `-bottom` (vertical gradient), `-ink` (glyph and text) and `-line` (1px border), plus `shadow-badge`. Size 18px high, `radius-sm`, `badge` text, 4px side padding; the `mini` size for calendar cells is 13px high, `radius-xs`, 9px text. The glyph is `currentColor`. The same component appears in the timeline Events column, the calendar cell, the matrix event rows, the Key legend and the day-view heading; never restyle it per screen. A Timeline row of badges is one line, centred; whole badges in priority order (vet, symptoms, note, photo, F, D), the rest folded into "+N" (neutral: `surface-tint`, `ink-2`, `line-strong`). On the Day view the `mini` note badge also marks a food or medication entry that has a note, in front of the note text (5px gap, aligned to the 12px text; JCB-130). The consumer provides the kind and the count.
